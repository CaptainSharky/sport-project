# Sport Project

**Sport Project** — фитнес-платформа в формате Telegram Mini App, предназначенная для планирования силовых тренировок, отслеживания прогресса и совместных занятий.

## Основные возможности

- **Персональные программы** — автоматическое формирование тренировочного плана на основе параметров пользователя и внутреннего алгоритма расчёта нагрузки.
- **Дневник тренировок** — запись рабочих весов, подходов, повторений и отслеживание прогресса.
- **Совместные тренировки** — добавление друзей, приглашения и проведение парных занятий.
- **Конструктор программ** — создание и редактирование собственных тренировочных планов.
- **Маркетплейс** — публикация, продажа и приобретение тренировочных программ других пользователей.
- **Telegram-интеграция** — идентификация пользователей и взаимодействие с платформой через Telegram Mini App.

## Технологический стек

*Планируемые технологии:*

- **Frontend:** React, TypeScript
- **Backend:** Java, Nest.js
- **Database:** PostgreSQL
- **Infrastructure:** Docker, GitHub Actions
- **Project Management:** Jira, Confluence

## Командная разработка

Для управления версиями используется Git и стратегия GitHub Flow.

- `main` — основная ветка проекта.
- `develop` — актуальная рабочая версия.
- `feature/*` — разработка нового функционала.
- `fix/*` — исправление ошибок.
- `docs/*` — изменение документации.

Все изменения в `main` и `develop` вносятся через Pull Request после Code Review и прохождения предусмотренных проверок.

## Документация

Требования, пользовательские сценарии, архитектурные решения и результаты проверок ведутся в **Confluence**.

Планирование задач и отслеживание прогресса разработки осуществляется через **Jira**.

## Статус проекта

В разработке. Проект находится на этапе проектирования архитектуры и организации командной разработки.
