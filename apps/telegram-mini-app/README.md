# Заглушка Smart Strength

Статическая страница для проверки открытия Mini App. Сборка и зависимости не нужны: для публикации разместите содержимое этой папки на HTTPS-хостинге. Файл `index.html` должен открываться по адресу приложения.

Для локальной проверки из этой папки запустите `python -m http.server 8000` и откройте `http://localhost:8000`. В браузере отображается подсказка об открытии через Telegram. После публикации настройте URL кнопки меню бота через BotFather (`/setmenubutton`), откройте кнопку в Telegram и проверьте сообщение о данных запуска и тестовую кнопку.

Страница не отправляет и не сохраняет данные запуска. Их наличие не подтверждает личность пользователя: для авторизации потребуется серверная проверка `initData`.

Обращения к Telegram WebApp SDK изолированы в `telegram-adapter.js`. Экран использует методы адаптера `prepareScreen()` и `hasLaunchData()`, не обращаясь к методам SDK напрямую.
